# TV-дизайн для больших экранов (ПК, ТВ, планшеты)

## Принцип
**Триггер — ориентация**: ширина контейнера больше высоты → TV-дизайн, иначе существующий телефонный. Телефон остаётся заблокированным в портрете (MainActivity `screenOrientation="portrait"`), поэтому там ничего не меняется — старый дизайн не трогаем вообще, весь новый живёт за ветвлением.

**Референс — Netflix/YouTube TV**: топ-бар с разделами вместо нижней пилюли, баннер-герой, горизонтальные ряды постеров, крупная сетка библиотеки, фокус-рамки для D-pad.

## Фаза 1. Фундамент (shared/jvmShared)
Новые файлы в `shared/src/jvmShared/kotlin/hd/kinoshka/app/ui/tv/`:
- **`TvLayout.kt`** — `@Composable fun rememberTvLayout(): Boolean` = `LocalWindowInfo.containerSize.width > height`. Единая точка переключения для всех экранов.
- **`TvComponents.kt`** — kit для D-pad и TV-эстетики:
  - `Modifier.tvFocusable(onClick, focusedScale = 1.06f)` — focusable + масштаб/рамка-подсветка (0xFF8AB4F8, как текущий акцент) + анимация;
  - `TvTopBar` — топ-навигация: логотип/аватар, разделы (Библиотека/Обзор/Лента/Ещё), поиск; элементы focusable, обход стрелками;
  - `TvPosterCard` — постер 2:3 с фокус-масштабом, прогресс-баром, статус-бейджем (переиспользует KinoshkaAsyncImage);
  - `TvHeroBanner` — широкий баннер с фоном, заголовком, мета и кнопками «Смотреть»/«В список»;
  - `TvRow` — горизонтальный ряд постеров с заголовком и фокус-обходом.

## Фаза 2. HomeScreen TV (`ui/tv/HomeScreenTv.kt`)
Отдельный композабл с **той же сигнатурой параметров, что HomeScreen** (state + callbacks уже подняты в FilmsViewModel — логика не дублируется). Ветка в начале `HomeScreen(...)` (HomeScreen.kt, ~5 строк): `if (rememberTvLayout()) { HomeScreenTv(...); return }`.
Разделы:
- **Обзор**: TvHeroBanner (продолжение просмотра из истории, иначе первый элемент каталога) + горизонтальные ряды (Популярное / Топ-250 / Сериалы — категории discover уже есть) + фильтр-кнопка;
- **Библиотека**: фокусируемые чипы-вкладки (История/Смотрю/В планах/...) вместо HorizontalPager-табов + крупный grid (адаптивные колонки от ширины) с TvPosterCard;
- **Ещё**: крупные фокусируемые карточки меню (Загрузки/Профиль/Настройки/О приложении/Календарь/Лента);
- **Поиск**: строка в топ-баре; инстант-поиск и история — как сейчас.

## Фаза 3. DetailsScreen TV (`ui/tv/DetailsScreenTv.kt`)
Двухпанельный landscape-макет:
- **Слева**: постер, название, рейтинг/мета, кнопки «Смотреть» и «В список» (фокусируемые), следующие серии/счётчик;
- **Справа** (прокручиваемая колонка): описание, сезоны/эпизоды вертикальным фокусируемым списком, похожие тайтлы (TvRow), кадры, детали.
Существующие private-композаблы DetailsScreen (ActionPanel-логика, SeasonsCard и т.п.) выборочно переводятся в `internal` для переиспользования; вся логика просмотра/озвучек остаётся в одном экземпляре. Ветка в теле DetailsScreen по `rememberTvLayout()`. Sheets (редактор профиля, выбор источника) остаются как есть — они работают в landscape.

## Фаза 4. D-pad + Android TV-обвязка
- **Фокус**: все интерактивные элементы TV-макетов через `tvFocusable`; LazyGrid/LazyRow получают корректный обход стрелками (Compose focus engine), возврат фокуса через `focusRestorer()`; `KinoBackHandler` уже общий. На ПК стрелки работают той же системой (клавиатура = D-pad).
- **Manifest** (app/src/main/AndroidManifest.xml): `LEANBACK_LAUNCHER` intent-filter, `<uses-feature android.software.leanback required=false>`, `<uses-feature android.hardware.touchscreen required=false>`, `android:banner` (новый drawable 320×180);
- **MainActivity**: разблокировка ориентации на больших экранах — в `onCreate` при `smallestScreenWidthDp >= 600` ставим `requestedOrientation = UNSPECIFIED` (телефоны остаются портретными);
- **Desktop Main.kt**: явный размер окна по умолчанию (1280×780), чтобы сразу открываться в TV-стиле.

## Фаза 5. Вторичные экраны (app-модуль)
Профиль/Настройки/О приложении/Загрузки/Календарь/Лента — без полной перерисовки: TV-обёртка `TvScreenScaffold` (топ-назад-фокус, контент центрирован max-width ~900dp, строки/кнопки через tvFocusable). RecommendationFeed и плеер остаются как есть (fullscreen).

## Верификация
1. `:app:compileDebugKotlin` + `:desktopApp:compileKotlin` зелёные после каждой фазы;
2. Портретное поведение не затронуто: ветвление только по `rememberTvLayout()`, все старые композаблы без изменений;
3. `graphify update .` (хук коммита);
4. Финальный прогон `:app:assembleDebug`.

## Ограничения/риски
- Профиль/Настройки на **desktop** не существуют (M5+ «нет экранов») — там TV-дизайн закрывает только Home/Детали/Плеер; перенос вторичных экранов в shared — отдельно.
- «Полностью новый дизайн» всех страниц за один прогон не сделаю без потери качества: фазы 1–4 дают основу + главные экраны с D-pad, фаза 5 догоняет вторичные страницы той же системой.
- Коммиты пофазно, чтобы можно было откатить.
