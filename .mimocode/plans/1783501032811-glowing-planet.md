# Plan: Auto-update check with bottom sheet on app launch

## Summary
Add a daily auto-update check that shows a `ModalBottomSheet` when a new version is found, offering the user to update. The update infrastructure already exists but is disabled and lacks a visible UI sheet.

## Changes

### 1. Enable the update feature flag
**File:** `app/build.gradle.kts` (line 46)
- Change `ENABLE_UPDATE_FEATURE` from `false` to `true`

### 2. Add release body to `AppRelease` data class
**File:** `app/src/main/java/hd/kinoshka/app/data/update/AppUpdateManager.kt`
- Add `val body: String` field to `AppRelease` (release notes from GitHub)
- Parse `"body"` from the JSON payload in `checkForUpdate()` and pass it to `AppRelease`

### 3. Modify auto-check flow in `KinoApp.kt` to show a sheet
**File:** `app/src/main/java/hd/kinoshka/app/ui/KinoApp.kt`
- Add a `var showUpdateSheet by remember { mutableStateOf(false) }` state
- Add a `var availableRelease by remember { mutableStateOf<AppRelease?>(null) }` state
- In the `runUpdateCheck` lambda, when `UpdateAvailable` is received and `installIfAvailable == false` (auto-check), set `availableRelease = checkResult.release` and `showUpdateSheet = true` instead of just showing a Toast
- Render the `UpdateAvailableSheet` composable conditionally when `showUpdateSheet` is true

### 4. Create `UpdateAvailableSheet` composable
**New file:** `app/src/main/java/hd/kinoshka/app/ui/components/UpdateAvailableSheet.kt`

A `ModalBottomSheet` with:
- Title: "Доступно обновление"
- Current version vs new version info
- Release notes (body text, scrollable)
- Download progress indicator during download
- "Обновить" button → triggers `AppUpdateManager.downloadApk()` then `launchApkInstaller()`
- "Позже" button → dismisses the sheet
- Uses the existing `ModalBottomSheet` pattern from `ProfileSettingsScreens.kt`
- Uses `KeepBottomSheetNavigationBarFromActivity()` for nav bar color consistency
