# Fix StarRatingIndicator — исправить отображение звёзд рейтинга

## Проблема
Текущая реализация `StarRatingIndicator` в `DetailsScreen.kt` рисует две отдельные иконки звезды: одну фоновую (прозрачную) и одну поверх неё (залитую), что визуально выглядит как "большие заполненные звёзды + малые заполненные звёзды".

## Как работает в ShikiWatch
`flutter_rating_bar` использует `ClipRect` — берёт одну и клиппирует её по ширине в зависимости от рейтинга:
```dart
RatingBarIndicator(
  rating: (score) / 2,  // 10-point → 5-point
  itemSize: 16,
  itemCount: 5,
  itemBuilder: (context, index) => Icon(Icons.star_rounded, color: primary),
)
```
Алгоритм: для каждой из 5 звёзд рисуется **одна и та же** иконка, но клиппируется по ширине (`fraction * itemSize`), показывая только залитую часть.

## Решение
Переделать `StarRatingIndicator` в `DetailsScreen.kt` (строки 3742-3783):

Для каждой из 5 звёзд:
1. Рисуем **одну** иконку `Icons.Rounded.Star` нужного размера
2. Оборачиваем в `Box` с `Modifier.drawWithContent`, который клиппирует содержимое по прямоугольнику шириной `fraction * size`
3. Фон — та же иконка с `alpha = 0.2f` (не нужна отдельная иконка, рисуем дважды через Canvas)

**Ключевое изменение:** использовать один `Canvas` на всю строку звёзд, где для каждой звезды:
- Рисуем полный контур звезды (alpha 0.2)  
- Рисуем залитую часть через `clipRect` с шириной `fraction * starSize`

Это тот же принцип, что и `flutter_rating_bar`.
